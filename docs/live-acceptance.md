## One execution command

After the real local services and reviewed source mapping are ready, run from this repository:

```powershell
node --experimental-transform-types src/live-run.mjs
```

The command loads the local ignored `.env`, checks configuration, uses the actual application investigator and critic, and saves `live.receipt.json` plus the returned `live.trace.json` under the ignored `.costproof/live/` directory. It uses a fresh memory directory to keep prior reports out of this baseline check. The existing memory suite separately proves reviewed-report recall across a process restart.

It requires all of these observations to pass:

- Registered synthetic sales, labor and policy records returned through real Zetaris network requests, with reviewed mapping, matching identifiers and full scope, one receipt per family and HTTP 200. The provider must match its explicit transport: `Zetaris REST` with `direct_rest`, or `Zetaris UI proxy` with `ui_proxy`.
- A real Nightshift discovery, source plan, explanation and critic response.
- Accepted model critique and exact numeric validation in the application.
- A valid fact-ID/check selection in the accepted attempt's unchanged model trace. Code resolves exact references from source records, records a separate fact-binding trace, and renders canonical text with every deterministic limitation. The gate recomputes this binding; a rendering label or approving critic alone is insufficient.
- The canonical shift scope and its $600 gap.

Read [the Nightshift provider contract](nightshift-provider.md) before evaluating model traces. Each application call uses a fresh request scope. If Nightshift 1.2.1 adopted MoA synthesis, a schema task always selects the receipt's preserved initial draft only after its request links, local Nano route, phase sequence and conservative token bound pass. The trace labels this `runtime_preserved_draft`; original provider finish and raw usage remain unknown, while final gateway finish and aggregate usage are separate. This is selection of returned model text, not JSON repair, and it cannot bypass schema, numeric, source or critic checks.

Fixture mode, injected test transport, missing sources, a rejected critic, an unverified preserved draft and model discovery without text cannot pass. An offline response replay checks adapter behavior only. A positive reported Runtime memory injection blocks an isolated request; absent injection metadata stays unknown. The process has a four-minute hard deadline. A deadline stops the process with a blocked error and no completed receipt; it cannot be counted as a pass. A normal failure exits nonzero and preserves a blocked receipt without raw provider errors or credentials.
