# Three questions. One evidence discipline.

Start the local server as described in the main README. The default previews need no cloud credentials or model download. All records are fictional.

## 1. Should I change the labor schedule?

Open `/`. The scoped labor gap is $600. The bridge separates the $420 sales plan effect from the $180 increase in wage dollars. Inspect the source stamps. Change the scenario to missing wages and the dollar conclusion stops. A remembered manager statement remains unverified and cannot rewrite payroll.

This is the primary agent workflow in the submitted 2:42 video and seven slide deck. Its October 24 sponsor run used three Zetaris queries, Meterless H-MEM and local Nightshift planning, evidence selection and critique. A preview run today is not a new sponsor run. Live mode fails explicitly when a service is unavailable.

## 2. Did the case price change, or the pack?

Open `/recipe`. The same fictional recipe costs $1.96 then $2.40 per serving. Inspect the vendor SKUs, invoice dates, purchase quantities and yields. Select the changed pack: the chicken case still costs $60, but its contents fall from 10 kg to 8 kg. Cost per gram rises 25%. The full recipe changes accordingly.

Missing yield holds the cost answer. The displayed menu comparison is ingredient cost only, before labor and overhead. It does not establish actual COGS, profit or savings.

## 3. Which void needs a closer look?

Open `/void`. Inspect original orders, void dollars and the rate denominator for the selected complete period. Cashier attribution, void initiator and manager approval are separate roles. Open the order event chain, then select missing kitchen evidence. A missing acknowledgment is an evidence gap. It does not establish that an employee ignored the instruction.

The new recipe and Void Hunter workflows are deterministic fixture previews. They do not call a POS, kitchen service, Zetaris or Nightshift. They demonstrate the same scope, source and uncertainty discipline beyond labor.

Each completed preview offers a JSON download containing the displayed result, source records, limitations and run identity. No review task is sent and no payroll, recipe, price or employee record is changed.
